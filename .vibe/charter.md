# Project Charter

> 详细契约见 `../设计方案.md`（v0.2），本文件为提炼版，作为契约入口。

## Objective

本地单人台账系统：统一管理昆山市科技局承接的国/省/市/本级科技项目（企业 / 项目 / 财政资金三维），支撑全生命周期跟踪、节点提醒、资金勾稽核对、企业画像、统计报表，并提供**只读 MCP 出口**供 Codex/WorkBuddy 等 AI 工具读库填表。

## Users and usage scenario

- 用户：昆山市科技局公务员（单人使用）。
- 场景：日常录入/查询台账 → 节点到期提醒 → 资金拨付登记与勾稽核对 → 出统计报表 → 用 AI 工具读库填写其他科室要的各种表格（AI 初填 + 人工核对）。

## Success metrics

对应 `设计方案.md` 第 3 节验收标准 A1–A8：

- A1 项目全貌几秒可查（层级/类型/企业/总金额/资金构成/当前阶段/下一节点）
- A2 企业画像（承担的全部项目/历史）
- A3 资金勾稽「上级+配套+自付」对得上、汇总不出错
- A4 节点到期前主动提醒，不漏
- A5 单文件备份即恢复
- A6 低配电脑流畅（启动 1~2 秒、内存几十 MB、瞬时响应）
- A7 MCP **只读**出口（AI 只能查询，无写操作）
- A8 配置界面自助增/停用类别，不改代码；停用不影响历史数据

## Non-goals

- 不做申报/审批流程（各级官方系统已承担）
- 不做多人协作、账号权限
- 暂不自动对接/抓取各级官方系统
- 不做移动端、云同步
- MCP 出口只读不写
- 台账核心不依赖 AI（纯确定性）

## Constraints and budgets

- 本地、单人、低配办公电脑（轻量、低资源占用）
- 台账核心零第三方依赖（Python 标准库 + SQLite）；MCP 阶段引入官方 `mcp` SDK 一个依赖（用户已确认）
- 金额单位统一「万元」，日期 `YYYY-MM-DD`
- 阶段预算：阶段 1–2 已完成；阶段 3–5 按迭代推进

## Unacceptable failures

1. 漏节点提醒
2. 资金统计/勾稽出错
3. 查全貌费劲
4. 数据丢失（无备份）

## Authority boundaries

- 用户：录入数据、配置类别取值、删除/改名等不可逆操作
- 系统：确定性计算（资金勾稽、节点提醒）自动执行
- AI（MCP）：只读查询，无任何写入权

## Assumptions

- 数据量几十~上百个项目/企业，SQLite 足够
- 配套比例由用户手工录入，系统不自动套政策公式
- 金额单位统一为万元

## Open decisions

- 附件/文档关联能力（给项目挂扫描件/批文 PDF）暂不含，待用户拍板
- 各字典初始种子值是否够用（可后续通过配置界面自助增补）
