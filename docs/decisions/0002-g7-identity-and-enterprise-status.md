# ADR-0002：项目编号补正与企业承接资格

日期：2026-08-14。决策人：HUMAN。

1. 项目可由人工录入而暂缺项目编号/文号，但请求必须显式给出 `identity_status=人工编号待补`；默认身份是 `正式编号`，因此缺少编号会被拒绝。Excel 自动导入继续要求项目编号/文号，不能借人工标记绕过。
2. 企业停用是独立于软删除的政务治理状态：历史企业和既有项目保留、默认可查询；停用企业不能承接新增项目；重新启用必须显式操作并填写理由。停用、启用均写入 `audit_log`。
3. 项目正式业务唯一键仍为“项目编号/文号 + 企业信用代码”。`人工编号待补` 项目尚未形成该正式唯一键，待补号后转为正式编号并接受唯一性校验。
