# G7 HTTP 越权响应中断回归

## 现象

`viewer` 与 `editor` 发出带 JSON 请求体的越权写请求时，服务端日志已记录
`403`，但 Windows 上的真实 HTTP 客户端偶发在读取响应状态行时收到
`ConnectionAbortedError (WinError 10053)`。

## 根因与修复

权限门禁位于 API 分发的前部。越权请求被直接返回 `401/403` 时，请求体尚留在
套接字接收缓冲区；服务端关闭连接后 Windows 会以 RST 终止连接，客户端因此无法
稳定取得已生成的响应。

现在，所有 `POST`、`PUT`、`DELETE` API 在进入鉴权前统一读取并缓存 JSON 请求体。
业务处理仍通过同一个缓存读取数据，不会二次消耗流。每个 JSON 响应明确完成并关闭
该短连接。

## 验证

目标权限回归测试连续三次通过，并执行全量 pytest 与统一检查脚本；测试只使用临时
数据库，正式库 SHA-256 保持不变。
