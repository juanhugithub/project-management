# 科技项目台账前端重构交接说明

## 包内文件

- `static/index.html`：单页应用结构。
- `static/style.css`：全部视觉样式和响应式规则。
- `static/app.js`：原生 JavaScript 交互、数据加载、表单与 API 调用。

项目没有使用 React、Vue 或构建工具。后端启动后通过 `/static/` 提供前端文件。

## 重构目标

面向单人使用的科技项目治理台账，强调办公效率、信息扫描、数据密度和政务可读性。可以重构布局、颜色、字体、组件结构和交互表现，但不能改变业务含义。

## 必须保留的业务口径

- 项目唯一键：项目编号/文号 + 企业统一社会信用代码。
- 项目阶段：申报中 → 已立项 → 实施中 → 待验收 → 已验收 → 绩效跟踪 → 已完结。
- 中止只能在立项后、验收前进入，进入后不能恢复。
- 单条资金记录同时包含金额、应拨日期、实拨日期和状态，不拆分计划表与实际表。
- 项目详情必须同时展示项目总金额、计划拨付、已拨付、已到账、待拨和勾稽状态。
- 停用字典项默认折叠，启用项支持拖拽排序。
- 更新入口、使用助手和使用分析必须保留。

## 技术约束

- `app.js` 通过 `/api/...` 调用本地后端，不能改成假数据或第三方云接口。
- 重构 DOM 时必须同步修改 `app.js` 中对应选择器，不能只改 HTML 导致交互失效。
- 所有用户数据输出继续使用 `escapeHtml`，不能直接插入未经转义的文本。
- 保持 1366×768、1024×768 和手机宽度可用，表格可滚动，关键按钮不可遮挡。
- 不引入必须访问国外 CDN 的字体、脚本或图标；单位电脑只能稳定访问国内网络。
- 不上传数据库、Token、备份或真实项目数据。

## 主要页面

- 工作台：项目和资金概览、待办节点、该拨未拨。
- 项目总览：筛选、列表、项目详情、资金和节点维护。
- 提醒：临期和逾期节点。
- 企业：企业档案和项目归属。
- 统计：按类型、层级、阶段、年度、企业和资金来源统计。
- 配置：字典停用、启用、拖拽排序和年度归档。
- 使用助手：日常操作和本地 Agent 接入说明。
- 使用分析：本机埋点统计。
- 检查更新：Gitee 热更新入口。

## 交付要求

Gemini 完成后应返回完整的 `index.html`、`style.css` 和 `app.js`，不要只返回视觉截图。必须保留现有功能，不能用静态示例替代真实 API 交互。
