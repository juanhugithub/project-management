先记住三件事

这套软件到底管什么？

一一条项目主线

从申报、立项、实施到验收和完结，阶段按规则流转。中止只能从立项后到验收前进入，进入后不能恢复。

钱一笔资金记录

一条记录同时记录金额、应拨时间、实拨时间和状态，不拆成“计划表”和“实际表”。

码项目唯一识别

项目编号/文号 + 企业统一社会信用代码共同识别项目，避免同名项目串在一起。

第一次使用

四步开始

  1. 先录企业进入“企业”→“新增企业”，先填名称和统一社会信用代码。
  2. 再录项目进入“项目总览”→“新增项目”，选择承担企业，填项目编号/文号。
  3. 补资金节点打开项目详情，在“资金明细”和“项目节点”区域添加记录。
  4. 看工作台回到“工作台”，查看待办节点、该拨未拨和资金事实。
日常操作

每天只做这些

  • 有新项目：新增项目，不要用备注代替项目编号。
  • 收到拨款：打开原资金记录，填写实拨时间并调整状态。
  • 节点完成：填写实际完成时间，将节点设为“已完成”。
  • 要报表：先用“统计”核对，再导出当前结果。
  • 要批量录入：下载 Excel 模板，填完后走预览和确认。
Agent 对接 · 本机免费版

让电脑上的 Agent 读取台账

当前不需要买服务器、不需要域名。Agent 和台账在同一台电脑上时，使用 MCP 本地连接即可。

1
确认本机服务

双击启动台账后，浏览器能打开台账页面，就说明本机服务已运行。

2
在 Agent 中添加 MCP

找到 Agent 的“工具 / MCP / 外部工具”设置，新增一个本地命令。

3
粘贴配置并测试

保存后让 Agent 调用“查询项目列表”。能返回项目数据，就接通了。

本机 MCP 配置
{
  "科技项目台账": {
    "command": "python",
    "args": ["E:/Reasonix WorkSpace/科技项目台账/mcp_server.py"]
  }
}
安装版用户把 command 改为实际安装目录中的 MCP 启动程序；源码版直接使用上方配置。
能让 Agent 做什么？读取项目事实、生成统计数据集、按模板整理表格、起草报告、把外部表头翻译成标准字段。正式台账写入仍需你在网页中确认。
表格翻译

字段对不上怎么办？

不要让 Agent 猜。先让它读取标准字段字典，再确认映射。

“批准文号”→project.project_no标准字段：项目编号/文号
“承担单位”→enterprise.name标准字段：企业名称
安全与边界

哪些事仍由你确认？

  • Agent 只读本地台账，不直接改正式数据。
  • Excel 导入必须先预览，再由人工确认提交。
  • 数据库、备份和导入原件都保存在你选择的本机目录。
  • 电脑关机时，本地 Agent 和手机都不能读取这台电脑的数据。
遇到问题

先看这里

Agent 提示找不到项目

确认 Agent 和台账运行在同一台电脑，并检查 MCP 配置中的路径是否真实存在。安装版不要照抄源码路径。

手机现在能直接连接吗？

暂时不能。当前版本不启用公网隧道，手机只能在以后配置 HTTPS 反向隧道后访问。

我改了电脑或数据库路径怎么办？

使用安装器的“配置目录”保存路径，不要手动移动数据库文件。修改后重新启动台账即可。
